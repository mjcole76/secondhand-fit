# Voice-over (read aloud, about 2:45)

Read at a calm pace. Each cue in brackets is what should be on screen; the timings match
`video-script.md`. About 390 words.

---

**[0:00 — Sell page, the seeded bad flat-lay appears]**

This is what a resale listing photo really looks like. A crumpled T-shirt on a checked duvet, half
in shadow. Send that to a virtual try-on and you waste API units on a render nobody can trust.

**[0:12 — scroll over the four checks and three instructions]**

Secondhand Fit catches it first. Four checks run right in the seller's browser: framing, background,
flatness and shadow. This photo fails three. Instead of a vague error, the seller gets three clear
fixes: use a plain surface, smooth out the creases, and even out the light. Zero API units spent.

**[0:35 — Seeded retake, grade A, drag the before/after slider]**

Here's the retake. Every check passes, and it earns an A. Then the server prepares the image for
try-on. It straightens it, strips the metadata, crops to the garment, flattens the background, and
sizes it to the YouCam API's input limits. The seller sees exactly what changed.

**[0:55 — choose Swimwear, refusal appears]**

Categories that shouldn't go through try-on, like swimwear, are refused before a photo is even
requested.

**[1:05 — Browse, open a listing, expand "Why this grade?"]**

Every listing shows a grade for its source photo. The grade comes from the weakest check, so one bad
result can never be averaged away.

**[1:20 — Try this piece on, consent screen, tick the boxes]**

Now the buyer's side. Before any photo leaves their device, buyers see in plain language what's
uploaded, where it goes, and when it's deleted. The server refuses any try-on without that consent.

**[1:35 — add your photo, Create preview, stages tick through]**

I'll add my photo and create a preview. The server calls the Perfect Corp YouCam Apparel Virtual
Try-On API. It uploads the garment and my photo, creates the task, and checks on it with a hard
time limit. Every step you see on screen is a real step on the server, not a progress bar on a
timer.

**[2:05 — the result; zoom in on the label, Download, Save to watchlist]**

And here's the result. Every render says exactly what it is: an AI-generated preview only, with no
claim about fit, size, condition or authenticity. It also shows how good the seller's photo was.
That label is built into the image, so it stays on every download and saved item.

**[2:20 — phone recording: rejection, then a listing]**

Sellers shoot on their phones, so the whole flow works in a mobile browser too.

**[2:30 — Status page, then the home page]**

A unit budget that fails safely. An offline mode, so anyone can run it from the repo. And honesty
on every render. Secondhand Fit: try-on for the listings that need it most.
