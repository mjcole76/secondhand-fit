## Required technologies
- **Devpost** — Mandatory [Official, High confidence]: Registration and submission platform for the hackathon.
- **Perfect Corp. YouCam API** — Mandatory [Official, High confidence]: At least one YouCam API must be integrated into a working web or mobile application; judging references the Skin, Beauty, Fashion, Jewelry & Watch, Hair & Beard categories.
- **YouCam AI Skin Analysis (Skin AI)** — Optional [Official, High confidence]: Named track/capability on the contest page: "Use YouCam's Skin AI, alone or combined with other YouCam APIs". Satisfies the "at least one API" requirement.
- **YouCam Apparel / Virtual Try-On (VTO)** — Optional [Official, High confidence]: Generative Apparel Virtual Try-On is highlighted as an available capability and as the eCommerce VTO track.
- **REST API (standard HTTP integration)** — Recommended [Official, High confidence]: Contest page states the YouCam models are exposed on "a standard REST API that drops into any stack".
- **YouCam API account (yce.perfectcorp.com/ai-api)** — Mandatory [Official, High confidence]: Entrants must create a free YouCam API account and redeem the code for 1,000 free API units.
- **YouTube (or Vimeo; Youku per contest page)** — Mandatory [Official, High confidence]: Demo video must be publicly hosted; YouTube highly preferred.
- **Public or shared code repository (e.g., Git hosting)** — Mandatory [Official, High confidence]: A repository URL with all source code, assets and instructions must be provided; specific host is not named.
- **Agentic AI workflows** — Optional [Official, Moderate confidence]: Contest page encourages but does not require building products that include "cutting-edge Agentic AI workflows"; no specific framework named.
- **Third-party SDKs/APIs and open source components** — Optional [Official, High confidence]: Permitted if the entrant is authorized under the relevant terms/licenses and builds on top of the underlying product.
